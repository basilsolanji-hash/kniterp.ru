# Сайт fabrika-ks.ru — копия главной страницы

Статическая вёрстка (HTML + CSS + JS, без сборки), повторяющая визуал главной страницы https://fabrika-ks.ru/.
Открыть: `site/index.html` в браузере.

- Цвета: фон `#1a1a1a`, шапка `#0a0a0a`, бирюзовый `#20b8ac`, плитки `#d8f2f1`; шрифт Manrope (Google Fonts).
- Шапка: логотип KS, поиск, кабинет, меню-«бургер»; плавающая кнопка корзины со счётчиком.
- `assets/hero.jpg` — временная картинка, вырезанная из скриншота; замените на оригинальное видео/фото.
- Сделаны блоки, видимые на скриншоте (первый экран, баннер, «О фабрике» с цифрами); остальные — по следующим скриншотам.
