## Что появилось в базе после вашего ответвления (11.10.2026)
- **D109 — защита.** Файлы `packages.lock.json` и `nuget.config`; CI и образ восстанавливают пакеты в locked mode. Добавили или обновили пакет —
  `dotnet restore` и закоммитить изменённые lock-файлы. Пакеты Microsoft — 10.0.12. `AccessGuard.CurrentAsync` отказывает заблокированному
  участнику; строки складского документа из API и заказов — только номенклатура своей организации.
- **D110 — автосмена этапа заказа покупателя.** Правила «событие → этап» (`SalesStageRule`, `StageAutomation`, миграция `AddSalesStageRules`).
  **Производству:** когда по заказу покупателя начато или завершено производство, вызывайте
  `SalesService.NotifyProductionAsync(salesOrderId, completed: false|true)` — этап сам станет «В работе» / «Собран» (только вперёд).
- **D111 — блок «Производство» на главном.** Интерфейсы в `Application/Workspace/ProductionDashboard.cs`:
  **производству** — `IProductionDashboardSource` (заказы в работе, готовность в %, выпуск за день, «требует внимания»);
  **«Сотрудникам»** — `IShiftStaffingSource` (смена сегодня: вышло / по плану / не вышли). Зарегистрируйте реализацию в DI своего модуля
  (`services.AddScoped<IProductionDashboardSource, …>()`); права на данные проверяйте сами по `AccessContext`; без прав верните null.
  Запросы — через переданный `IKnitErpDbContext`, без параллельных вызовов.
- **D112 — свои роли и особые права.** `Role.CreateCustom`, `RoleService`, `Permissions.GroupOf`: новое право с префиксом кода
  (`production.`, `hr.`, `catalog.`) само попадает в свою группу редактора ролей — достаточно дописать его в `Permissions.Labels` и `RoleMatrixP0`.
  Право с управлением пользователями делает роль административной.
- **D113–D114 — интерфейс.** Главный экран начинается с «Динамики за 30 дней»; компактный интерфейс по умолчанию, размер — в профиле
  (атрибут `data-density` у `<html>`). Новые стили пишите без фиксированных 44px: высоту касания задают общие правила.
