# Интерфейс (сессия 5, `claude/ui-review`) — сообщения другим сессиям

Ветка `claude/ui-review` от базы `claude/fervent-volta-3pn88r`. Решения — D800–D899 (`docs/decisions.md`, раздел «Интерфейс всех экранов»).
Мои файлы: `MainLayout`, меню, верхняя панель (`QuickBar`), блок пользователя (`ProfileMenu`), `SideFooter`, общие стили `App.razor`,
`Components/Shared/*`. Экраны `Dev*.razor` пересматривает сессия «Разработка».

## Что изменилось для всех (13.10.2026)
- **Меню (D800, `docs/ui/menu.md`).** Пункт меню — `I(адрес, название, право, подзаголовок)`; подзаголовки — константы `SDocs`, `SPrices`,
  `SReports`, `SOrg`, `SModules`, `SExchange`, `SControl`. Пункты без права больше не показываются (сервер проверяет как раньше);
  пунктов «скоро» нет. Новый экран модуля — одной строкой в своём разделе; настройки модуля — в «Настройки → Модули».
- **Верхняя панель и профиль (D801, D802).** Профиль — в правом краю верхней панели, а не внизу меню слева.
- **Без предварительной отрисовки (D803).** Интерактивные страницы рисуются только после подключения схемы. В e2e после `goto` по-прежнему
  ждите готовности (`ready(page)` / подключения Blazor); статического HTML страницы до подключения больше нет.
- **Цели нажатия 44 px** на сенсорных экранах (D801) — не задавайте кнопкам и полям `min-height` меньше.

- **Меню v2 (D805).** `MainLayout.Groups`, `NavGroup`, `NavItem` — публичные (их читает страница раздела `section/{ключ}`).
  В меню видны 3–7 частых пунктов раздела (`MainHrefs`), остальные — на странице раздела. Новый частый экран — добавьте адрес в `MainHrefs`.
  На телефоне (≤899 px) меню открывает «Ещё» в нижней панели `nav.bottom-nav`; кнопка «Меню» в шапке скрыта. В e2e для телефона
  открывайте меню так: `page.Locator("nav.bottom-nav").GetByRole(AriaRole.Button, new() { Name = "Ещё" })`.
- **Верхняя панель v2 (D806).** Порядок: Поиск, Создать (меню «новых» действий из `DashboardActions` по правам), закреплённые инструменты.
  У каждого значка подсказка и `aria-label`. На телефоне — Поиск, Создать, Уведомления и «Ещё».
- **Блок пользователя v2 (D807).** Кнопка: аватар, имя, «должность · организация». Пункты: «Профиль и пароль» (`security#password`),
  «Сессии и устройства» (`security#devices`), «Обучение», «Поддержка». «Рабочий день» внизу меню свёрнут в одну строку.

- **«Настройки» — один пункт (D808).** Пункт ведёт на `MainLayout.SettingsHref` (сейчас `section/settings` — плитки из группы
  `settings` в `MainLayout.Groups`). **Сессии № 1:** когда будет страница `/settings` (этап 2б), сообщите — сменю адрес; плитки
  на ней можно строить из той же группы `settings` (подзаголовки `SOrg`, `SModules`, `SExchange`, `SControl`), чтобы список настроек был один.
  Новая настройка модуля — строка `I(адрес, название, право, SModules)` в группе `settings`.
