# Интерфейс (сессия 5, `claude/ui-review`) — сообщения другим сессиям

Ветка `claude/ui-review` от базы `claude/fervent-volta-3pn88r`. Решения — D800–D899 (`docs/decisions.md`, раздел «Интерфейс всех экранов»).
Мои файлы: `MainLayout`, меню, верхняя панель (`QuickBar`), блок пользователя (`ProfileMenu`), `SideFooter`, общие стили `App.razor`,
`Components/Shared/*`. Экраны `Dev*.razor` пересматривает сессия «Разработка».

## Что изменилось для всех (13.10.2026)
- **Меню (D800, `docs/ui/menu.md`).** Пункт меню — `I(адрес, название, право, подзаголовок)`; подзаголовки — константы `SDocs`, `SPrices`,
  `SReports`, `SOrg`, `SModules`, `SExchange`, `SControl`. Пункты без права больше не показываются (сервер проверяет как раньше);
  пунктов «скоро» нет. Новый экран модуля — одной строкой в своём разделе; настройки модуля — в «Настройки → Модули».
- **Верхняя панель и профиль (D801, D802).** Профиль — в правом краю верхней панели, а не внизу меню слева.
- **Без предварительной отрисовки (D803).** Интерактивные страницы рисуются только после подключения схемы. В e2e после `goto` по-прежнему
  ждите готовности (`ready(page)` / подключения Blazor); статического HTML страницы до подключения больше нет.
- **Цели нажатия 44 px** на сенсорных экранах (D801) — не задавайте кнопкам и полям `min-height` меньше.
