# Автоматизация и минимум ручного ввода — предложения (сессия № 4, 11.10.2026)

Цель: пользователь вводит данные один раз, остальное система подставляет, считает и создаёт сама. Ниже — где сейчас приходится печатать
руками и что предлагается. Обследование кода — по состоянию ветки `claude/catalog-products` (пути — от `kniterp/src/`).

Обозначения: **Кто** — сессия-владелец модуля (№ 1 — продажи, закупки, склад, деньги; № 2 — производство; № 3 — сотрудники;
№ 4 — каталог и обмен). **Эффект** — сколько ручного ввода снимает: ★★★ — ежедневно и массово, ★★ — регулярно, ★ — иногда.
**Статус**: ✅ сделано, 🔧 делается сессией № 4 сейчас, 📨 запрос владельцу модуля.

## Уже автоматизировано (для справки)
Номера документов; поиск позиции в строке по коду, артикулу и штрихкоду (сканер-клавиатура); НДС и цена в строке из карточки и вида цен;
отгрузка, возврат и счёт «на основании» заказа; разнесение оплат и авансов; ввод инвентаризации от учётных остатков; строки складских
документов из Excel; реквизиты контрагента по ИНН (DaData); код позиции, внутренний EAN-13 и артикул по счётчику (D312, D315);
наименования модификаций из характеристик; этикетки по шаблону (D316); загрузка каталога из МойСклад (D310); фид для площадок (D314).
