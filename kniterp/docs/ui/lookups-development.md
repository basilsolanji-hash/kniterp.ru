# Справочники «Разработки» — опись (запрос владельца 13.10 §2, решения D733, D734)

Справочники модуля — записи `dev_lookups` своей организации: «Настройки разработки → Справочники». Свой вариант — «Добавить», встроенные
можно переименовать и отправить в архив (архивная запись остаётся у объектов, которые на неё уже ссылаются, но не предлагается для новых).
Типовые значения — каталог `DevLookupCatalog`: организация получает их при первом обращении к разработке, новые значения каталога —
при следующем, без дублей (встроенная запись узнаётся по коду, своя — по названию). Производители станков существующим организациям
создала миграция `DevMachineLookups`, категории и виды рисунков — `DevCategoryLookups`.
