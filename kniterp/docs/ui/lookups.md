# Опись справочников knitERP (раздел 0 п. 5 ТЗ интерфейса; запрос владельца 13.10, п. 2)

Сессия 5 «Интерфейс» ведёт список; **наполняют свои справочники владельцы модулей** (запрос владельца 13.10, п. 2: максимум
типовых значений для трикотажной и швейной фабрики; новая организация получает их при создании, существующая — миграцией данных
без дублей; значения можно архивировать, переименовать, добавлять свои). Сверено по коду 13.10.2026.

Обозначения: **Типовые** — заполняются ли значения по умолчанию и сколько; **Свой вариант** — можно ли добавить значение прямо
из списка выбора («+ Добавить «…»»), не уходя на страницу справочника.

## Итог
- Типовые значения при создании организации (`OrganizationService.CreateWithOwnerAsync`): единицы, причины складских операций,
  этапы заказов и правила их смены, основное юрлицо, основной вид цены, статьи ДДС, ставки НДС. При первом открытии: воронка CRM,
  этапы, источники и причины проигрыша; причины отмены заказа, способы доставки, причины возврата.
- **«Свой вариант» прямо в списке есть только у тегов** (`TagPicker`, право «Теги: управление справочником»). У всех остальных —
  только на странице справочника. Свободный ввод с подсказками (datalist): страна происхождения, основание кассового ордера,
  детали и точки измерения «Разработки», единицы сдельной расценки, причины брака.
- **Причины отмены заказа нельзя изменить нигде в интерфейсе** — метод сервиса `CreateCancelReasonAsync` есть, экрана нет.
