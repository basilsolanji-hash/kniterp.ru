# Пересмотр экранов «Разработки» — «было → стало» (ui-review §0 п. 4)

13.10.2026, сессия «Разработка», решение D731. Общий файл находок `docs/ui/findings.md` ведёт сессия интерфейса; здесь — только экраны
`Dev*.razor`. MainLayout, меню, верхняя панель, блок пользователя, общие стили и `Shared/*` не менялись.

**Снимки:** тест `DevScreenshotTests.Capture_review_screens` (переменная `KNITERP_REVIEW_SHOTS=<папка>`). Он снимает каждый экран
на 1440 и 390 px в светлой и тёмной теме (`<экран>-<ширина>-<тема>.png`) и пишет замеры `metrics.jsonl`: число основных кнопок,
прокрутку вбок, мелкие зоны нажатия, текст с контрастом ниже WCAG AA, лишние нули в полях. Снимки «было» и «стало» в репозиторий
не кладутся (ТЗ §3), их пары переданы владельцу.

## Передано сессии интерфейса
1. Контраст ссылок в светлой теме (`a { color: var(--accent) }` ≈ 4,41:1) — нужен более тёмный цвет ссылок.
2. `Shared/Discussion.razor`: «Отправить» — основная кнопка на каждом экране с обсуждением.
3. Ввод в первые секунды после открытия теряется — e2e модуля повторяют нажатие и проверяют результат (`DevUi`).
