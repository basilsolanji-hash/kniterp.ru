# CRM: предложения по автоматизации и минимизации ручного ввода

Версия 1.0 от 12.10.2026, сессия CRM (`claude/crm`). Решения — D660–D679 в `docs/decisions.md`. Всё ниже реализуется в ветке
вместе с этапами 2–5 ТЗ CRM; каждое правило можно выключить в «Настройки CRM → Автоматизация».

Принцип: менеджер вводит только то, чего система не может узнать сама. Остальное подставляется из базы knitERP, внешних
справочников и событий; спорные действия система **предлагает** (одно нажатие), а не делает молча.

## 1. Ввод лида
| № | Сейчас вручную | Предложение | Экономия |
|---|---|---|---|
| А1 | Перепечатать сообщение клиента в поля | **Умная вставка**: вставить текст из мессенджера или письма — система сама находит телефон, почту, ИНН, «ООО «…»», количество и изделие («300 свитеров»), имя из подписи | 5–8 полей на лид |
| А2 | Набирать реквизиты контрагента | **Реквизиты по ИНН** (ЕГРЮЛ/ЕГРИП, механизм базы D78): при квалификации наименование, КПП и адрес подставляются сами | 3–4 поля, ошибки в реквизитах |
| А3 | Заводить заявки с сайта и маркетплейсов | **Приём заявок через API** (`POST /api/v1/crm/leads`) с проверкой дубликатов: повторное обращение становится активностью найденного лида | весь ввод заявки |
| А4 | Записывать звонки | **Звонки из телефонии** (`POST /api/v1/crm/calls`): звонок по номеру находит контакт, лид или сделку и пишет активность; незнакомый номер — новый лид | запись каждого звонка |
| А5 | Переносить базу из amoCRM / Битрикс24 | **Импорт** с автоматическим сопоставлением столбцов и этапов по названию, повторная загрузка без дублей (внешний id) | перенос базы |
| А7 | Переписывать сообщения из мессенджеров | **WhatsApp, Telegram, MAX** — общий приём `POST /api/v1/crm/messages`: сообщение попадает в ленту контакта, сделки или лида (по телефону или нику), незнакомый отправитель — новый лид с разбором текста (А1) | весь ввод переписки |
| А6 | Решать, кому отдать заявку | **Автоназначение**: заявки из API и импорта — по очереди между менеджерами продаж (или на одного ответственного) | ручное распределение |

## 2. Ведение сделки
| № | Сейчас вручную | Предложение |
|---|---|---|
| Б1 | Ставить задачу после этапа | **Следующий шаг по этапу**: на «КП отправлено» — «Позвонить через 3 дня», на «Образцы / расчёт» — «Уточнить получение образцов через 5 дней»; система предлагает, менеджер подтверждает |
| Б2 | Двигать сделку по этапам | **Автосмена этапа по событиям**: отправлено КП → «КП отправлено»; создан заказ → «Согласование»; заказ подтверждён → «Выиграна» (только вперёд) |
| Б3 | Считать сумму | Сумма = сумма позиций; цены — из основного вида цен; вероятность — из этапа |
| Б4 | Угадывать дату закрытия | **Плановая дата по умолчанию** = сегодня + средняя длительность выигранных сделок организации (нет истории — 30 дней) |
| Б5 | Делать КП в Word | **КП одной кнопкой** из позиций сделки и вида цен, печать/PDF, **отправка письмом** контакту; фиксируется активность с номером и суммой |
| Б6 | Писать клиенту из почты | **Письмо из карточки** лида, сделки или контакта — уходит с сервера и сохраняется в ленте |

## 3. Контроль и повторные продажи
| № | Предложение |
|---|---|
| В1 | **Напоминания в колокольчике**: просроченные задачи, сделки без следующего шага, лиды без действий дольше N дней (по умолчанию 3) |
| В2 | **Повторная продажа**: после выигрыша сделки — задача «Предложить повторный заказ» через N дней (по умолчанию 60) |
| В3 | **Рассылки** только контактам с согласием на рекламу (38-ФЗ), отписка по ссылке в письме без входа; кто, когда и кому отправил — в журнале |
| В4 | **План / факт** считается сам: факт — оплаты по заказам из сделок (или выигранные сделки), без ручных сводок |

## 4. Сделано 12.10.2026 (D670–D679)
- **Мессенджеры**: Telegram, WhatsApp, MAX — чаты с клиентами, подключение бота в «Настройках CRM», ответ из knitERP (D670–D673).
- **Почта**: шаблоны с переменными, HTML-письма с ответом менеджеру, очередь и расписание рассылок, входящие письма из ящика по IMAP (D674–D676).
- **Защита**: подпись и секреты вебхуков, лимиты, запрет внутренних адресов для IMAP, удаление ПДн в переписке, лимит писем (D673, D676–D678).

## 5. Что остаётся следующим шагом (решение владельца)
- Шаблоны сообщений WhatsApp вне 24-часового окна; рассылки в мессенджерах по согласию (38-ФЗ).
- IP-телефония с записями разговоров.
- Подсказка «следующее лучшее действие» помощником (D116) — после отдельного решения.
