# База знаний помощника (D900–D999)

ТЗ — `docs/tz/knowledge-base.md`. Помощник (Ника и Книт) и панель «Справка» ищут по одному индексу: справка программы
(`HelpCenter`), отраслевые статьи (`Knowledge/*.json`, D116) и готовые ответы (`Knowledge/qa-*.json`, D900).

## Где что лежит
| Что | Где |
|---|---|
| Ответы (JSON, встроены в сборку) | `src/KnitErp.Application/Workspace/Knowledge/qa-<раздел>.json` |
| Синонимы | `src/KnitErp.Application/Workspace/Knowledge/synonyms.json` |
| Загрузчик, поиск, стеммер | `Workspace/Knowledge/KnowledgeAnswers.cs`, `KnowledgeSearch.cs`, `RussianStemmer.cs` |
| Исходники ответов (компактный текст) | `docs/kb/src/<раздел>N.txt` |
| Сборка JSON, тестовый набор, варианты | `docs/kb/tools/conv.py`, `evalconv.py`, `addvar.py` |
| Тестовый набор точности | `docs/kb/eval.json` (исходник — `docs/kb/src/eval-*.txt`) |
| Снимки экрана помощника | `docs/kb/screens/` (e2e `AssistantKbE2ETests`, переменная `KNITERP_SCREENSHOTS`) |

## Формат исходника
```
Q: Вопрос, как его задаёт человек?
V: вариант 1 | вариант 2 | вариант 3
A: Первый абзац ответа — шаги, кнопки «как на экране».
A: Второй абзац.
L: экран-1 экран-2?параметр=1
R: Владелец | Бухгалтер
S: Источник — https://адрес (обращение 2026-10-12)     ← для отраслевых и правовых ответов, минимум два
E: advanced                                            ← необязательно, по умолчанию basic
```
Пустая строка разделяет ответы. Сборка: `python3 docs/kb/tools/conv.py <ключ> docs/kb/src/<ключ>*.txt`. id выдаётся один раз и сохраняется по тексту вопроса: меняя формулировку
вопроса, перенесите id вручную.

## Правила
- Ответ о программе пишется по коду и экранам текущей версии; при изменении экрана ответ правится (тест ссылок помогает).
- Отраслевой и правовой ответ — пересказ своими словами, два независимых источника с адресом и датой обращения, норма — только из
  официального текста; у меняющихся норм — «проверьте актуальную редакцию».
- Статьи модулей (`production-*`, `hr-*`, `catalog-*`) пишут их сессии; эта база их не переписывает.

## Цикл «обучения»
1. Вопросы, на которые помощник не нашёл уверенного ответа или получил «Не помогло», — отчёт «Пробелы базы» (этап 5).
2. Из отчёта — новые ответы, варианты формулировок (`addvar.py`) и синонимы (`synonyms.json`).
3. Новые типичные формулировки — в `docs/kb/src/eval-*.txt` → `evalconv.py` → `eval.json`; тест точности не должен падать.
